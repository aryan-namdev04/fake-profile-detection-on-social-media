# Fake Profile Detection on Social Media

A secure MERN Stack web application that analyzes social media profiles and detects potentially fake or suspicious accounts based on different profile parameters.

---

## Features

- User Signup
- User Login
- Password Hashing using bcrypt
- Session-based Authentication
- Protected Routes
- Fake Profile Detection
- Analysis History
- User Dashboard
- Welcome User
- Logout Functionality
- Responsive User Interface

---

## Installation

### Clone Repository

```bash
git clone <repository-url>
```

### Install Dependencies

```bash
npm install
```

### Start Server

```bash
npm start
```

or

```bash
npm run dev
```
